Security

This repository follows DEFRA's security policy. https://github.com/DEFRA/.github/blob/main/SECURITY.md

Reporting a vulnerability

Please follow DEFRA's official vulnerability-reporting process. https://www.gov.uk/guidance/report-a-vulnerability-on-a-defra-system

Do not report security vulnerabilities through public GitHub issues, discussions or pull requests.

Include the repository name, affected tag or commit, relevant configuration, steps to reproduce and potential impact. Do not include credentials or personal data.
